## 几个高频问题

**200M峰值带宽和3M、4M固定带宽到底怎么比？**
200M是峰值上限，不承诺全程跑满；3M、4M是固定带宽，稳定给到这个值。下载速度上3M约384KB/秒、4M约512KB/秒。图床、静态站这类流量大但对稳定带宽不敏感的场景，峰值带宽体验更好；视频会议后端等实时业务，选固定带宽更可预期。

**腾讯云轻量的流量超了要花多少钱？**
超出部分按0.8元/GB计费。300GB月流量折合每天约10GB，消耗可预估且用不满就选腾讯云；反之选不限流量的阿里云，或者直接上两家都不限流量的ECS/CVM机型。

**已经在用一家的服务器，有必要换吗？**
没必要为迁而迁。两家云服务器之间不支持直接快照迁移，换平台意味着重装环境、重新部署，迁移成本通常大于差价。有新增需求时，用另一家的账号开台新机更实际。

**备案哪家方便？**
两家都支持在线提交，流程类似。有用户反馈阿里云实名认证审核更严格，腾讯云的备案辅助流程相对宽松。境内节点建站必须完成ICP备案，用香港等境外节点则不需要。
